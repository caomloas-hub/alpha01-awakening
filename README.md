# 风从旧世来

一个 1920×1080 的中文第一人称福瑞视觉小说原型，使用 Ren'Py 8.5.3 制作。当前开发快照为 v0.2.2，包含序章与城镇路线第一章《借名入城》。“ALPHA-01”保留为剧情中的实验编号，“苏醒记录”则是游戏内档案功能名称。

![灰桥城首次入城](game/images/town_route/cg/cg-town-first-city-view-v2.png)

## 当前内容

- 木质中国法庭的近景开场，支持“抗辩 / 沉默”两种不改变判决、但改变人物状态的回应。
- ALPHA 原型体实验与两千年文明演进转场。
- 地震、未知授权和最终预案触发的强制唤醒。
- 可自由决定调查顺序的地下设施探索。
- 地下探索采用第一人称 POV，不叠放万能全身立绘；身体确认按“掌心→抬头→镜像”连续演出。
- 镜前采用默认名“敖浔奕”或输入自定义名字。
- 篇章-VI 神经加速测试，以及由前置调查解锁的地表隐藏选项。
- 地表三路线入口：村庄、城镇、流浪者；当前完整开放城镇路线，其余两线保留开发预告。
- 城镇路线 T01～T07：观察商路、断轴接触、商队雇签、羊皮纸地图、第一人称换装、劳动分支、验籍入城、临时准入证明与岚的夜谈。
- 城镇线现有断轴救援、换衣、王国公路、南市、南栈院登记和通铺房等事件 CG；商队地图配有独立兽爪指示动画。
- 三种城门掩护说法和三种工作选择均保留各自反馈，并汇入同一合理结果。
- 标题与菜单改用同一套旧世遗迹视觉体系；整张带字按钮参与悬停、确认与退场动画。
- Esc / 右键暂停，保存、读取、对话记录、设置、快速保存/读取和苏醒记录二级菜单均保留。

## 操作

- 鼠标左键 / Enter：推进、确认。
- Esc / 鼠标右键：打开暂停菜单；在二级菜单中返回暂停页。
- Ctrl：快进。
- 鼠标滚轮向上：回退。
- F：窗口 / 全屏切换（Ren'Py 默认快捷键）。

## 本地运行

1. 安装 [Ren'Py 8.5.3](https://www.renpy.org/) 或兼容版本。
2. 将本仓库目录添加到 Ren'Py Launcher，或在命令行运行：

   ```text
   renpy <项目目录> run
   ```

3. 开发检查可依次运行 `lint` 与 `compile`。构建产物不会提交到仓库。

## Android 测试版

Android 测试构建使用 Ren'Py 8.5.3 对应的 RAPT、JDK 21 与 Android API 36，包名为 `com.caomloas.alpha01awakening`，采用横屏显示且不启用商店内购。构建环境、真机部署和签名注意事项见 [Android 测试构建说明](docs/ANDROID_TEST_BUILD.md)。APK 作为测试发行附件提供，不把签名密钥或本机 SDK 路径提交到仓库。

## 路线状态

序章内部记录 `resolve`、`caution`、`empathy`、`tech_insight` 与记忆碎片。城镇线额外记录商队信任、岚的关系、掩护说法、工作选择、临时准入证明与床位。离线核心和原型体记录继续保留，作为后续章节的回响，不再代替地表出身路线选择。

## 素材说明

人物、背景、CG 与地图为本项目生成素材。当前版本遵守第一人称叙事：主角不以万能全身立绘常驻，NPC 设定图也不作为带白底的成品立绘硬塞入场景；角色主要通过事件 CG、姓名框与对白呈现。临时准入证明只以斜置木牌和黄色获得提示出现，不展示现代公文式信息面板。

声音仍处于分段制作阶段：当前已接入设施底噪、商路音乐与环境声、事件音效，以及较轻的机械木质界面反馈音。后续声音重构方案见 [声音设计计划](docs/AUDIO_DIRECTION.md)。在第三方音效完成选型和授权登记前，不会把来源不清的音频纳入公开仓库。

## AI 制作与开发公示

本项目在制作过程中使用了生成式 AI 辅助，公开说明如下：

- 人物设定图、背景、地图、界面素材和事件 CG 含有 AI 生成或 AI 编辑内容。
- 剧本初稿、对白润色、连续性检查、Ren'Py 程序实现、测试与项目文档由创作者与 AI 协作完成。
- 世界观、路线方向、人物关系、审美取舍、修改意见以及最终验收由项目创作者主导；生成结果经过人工筛选和多轮修改后才会接入游戏。
- 后续加入的第三方声音素材不会冒充 AI 生成或项目原创，将单独记录来源、作者、许可证和修改情况。

本公示用于如实说明制作流程，不代表仓库内素材自动获得开放授权；具体使用边界仍以本 README、后续许可证及第三方素材记录为准。
