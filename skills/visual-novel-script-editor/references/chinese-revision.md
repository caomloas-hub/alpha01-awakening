# 中文剧本文句修订

用于中文台词与叙述的改写；不是把所有文本口语化的规则。以下例句是说明方法的自拟例句，不是作者已验收的正文。

## 先诊断，再选择改动

- 矛盾：人物知识、数量、先后或分支事实对不上，优先核实上下文。
- 表达障碍：句子能还原成明确意思，但句式遮住了动作或诉求，局部重写。
- 空转：用一句朴素的话复述后，没有增加信息、情绪、关系或节奏，考虑删减。
- 风格差异：意思清楚且符合人物，只是不够口语，不必改。

朴素复述是诊断手段，不要求成稿全是白话。观察整段最突出的重复模式：可能是连续对仗、每句收尾升华，也可能是不断低头、攥拳、停顿。不要用另一套身体动作模板取代格言模板。

## 双向核对

从原文到改文：有无丢掉限制条件、承诺、拒绝、保留态度、关键称谓或伏笔？
从改文到原文：新增的事实、动机、经历和判断有没有来源？是否把“我猜”变成了“他就是”，把“可能”改成“必定”，把没有说出口的想法变成他人听过的话？

特别检查中文省略主语、代词、否定范围与时间词。修顺一句话，不能把“没说会留下”变成“说了不会留下”。数额、日期与约定分开核对，不凭读感放行。

## 对照例

| 情境 | 编辑判断 |
| --- | --- |
| “他没再问。我也没说。”双方有意保留身份 | 保留。重复承担互相回避的节奏，不机械合并 |
| “我还不能确定这条路通向哪里。” | 不改成“这条路通向危险”。后者新增结论 |
| “这一决定重新定义了我与城市的关系。”当前只是拿到通行牌 | 可写“我把木牌收好。下一道关口，总算有东西能递出去了。”前提是木牌及关口用途已经成立 |
| 守门人说“出示雇签，保人留在原地。” | 保留正式措辞。职务现场不需要网络口语 |
| 旁白“我只听懂七成”；下一幕 NPC 说“你刚说只懂七成” | 知识越界。改为 NPC 可观察到的反应，或在已获授权范围内补真实交流；不默认为他能听见旁白 |

不要为“像人写的”新增错字、随机口头禅、虚构亲历、夸张数字或刻意凌乱。不要以不可检测、通过检测器为目标；本作可以公开 AI 制作，文学质量仍由读者体验决定。
