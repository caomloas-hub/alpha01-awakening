# 第一章·城镇路线设计案 V0.2

## 一、这一轮的开发边界

本文件只设计第一条可开发路线：

> 地表路线选择“沿着国道边缘前进” → 在第 21 号王国公路遇见赶往首都灰桥城的商队 → 以临时脚夫身份换装、随队进城 → 取得三十日短籍 → 入住商队栈院。

暂定章节名：**《借名入城》**。

本章预计正常阅读 55～75 分钟。它需要完成四件事：

1. 让敖浔奕第一次与新时代的普通人进行持续交流。
2. 用劳动、担保和短籍制度，让“进入城市”成为一件有成本、有程序的事。
3. 自然完成城镇路线服装替换，不再穿着地下设施的贴身实验服活动。
4. 建立商队少年“岚”的专属关系线，但本章不锁定恋爱、友情或背叛方向。

本章不做以下事情：

- 不揭晓人类灭亡真相。
- 不让商队成员立即相信两千年休眠经历。
- 不把路线选择写成善恶、哲学或人格测试。
- 不使用“选错即进不了城”的假分支。
- 不在第一章让敖浔奕成为英雄、官员或核心人物。
- 不把岚写成只负责卖萌和讲解设定的工具人。

## 二、继承的序章事实

- 主角默认名为“敖浔奕”，也允许沿用玩家自定义姓名。
- 主角是白蓝配色、带角、长耳和尾巴的龙类兽人，原本是旧人类时代的 ALPHA-01。
- 主角携带军用神经加速框架“篇章-VI”，但在公众面前启动会增加暴露风险。
- 主角可能携带绷带、净水片和失效时间未知的医疗物资。
- 主角可能带走设施离线核心，也可能留下原型体纪念标记；这些不再决定路线。
- 主角的基本行为方式仍是观察、拆分变量、控制风险，不用固定口头禅反复强调“理性”。
- 本路线继续采用主角第一人称 POV。除镜面、明确事件 CG 或后续经过讨论的第三人称演出外，不把主角全身立绘常驻在画面上。

## 三、城镇与语言设定

### 3.1 灰桥城

灰桥城是荟屿国的首都，也是西南商路汇入王畿的第一座大型关口城市。它依托旧高速高架、桥墩和山谷水道扩建而来，城墙的一部分直接利用了人类时代的混凝土结构。王宫与行政区位于更深的内城；商队从西南方向抵达时，首先面对的仍是货运关卡、外市和栈院，而不是一眼望见宫殿。

城市分为四个玩家第一章能接触到的区域：

1. **西关道**：商队排队、修车、缴税和等待开门的道路。
2. **验籍门**：核对行脚牌、货单和临时雇工身份的关卡。
3. **南市外街**：低价旅店、修理铺、食摊和临时工聚集区。
4. **南栈院**：商队长期租用的货栈与通铺，也是主角第一晚的住处。

第一章只展示城市的外层生活，不进入王宫、贵族区、学院或宏大政治机构。

### 3.2 三条路线共用的地图演出

三条出身路线参照同一份只供开发使用的真实地理关系，但玩家看到的地图道具彼此不同：商队使用正规交通图，村民使用林地与猎区草图，流浪者家族使用迁徙、水源与遗迹图。每条路线由相应角色摊开自己的地图，并用自己的兽爪指出地点。这样既不会让地理互相矛盾，也能让地图本身表现持有者如何理解世界。

地图采用中古世纪手绘地图语言，但不画成只供装饰的奇幻卷轴：

- 底材为有折痕、磨损和局部水渍的旧羊皮纸。
- 山脉、河流、城镇和国界使用手工墨线与少量褪色矿物颜料。
- 灰桥城使用首都徽记标识，但不夸张成覆盖地图的大城堡。
- 王国公路以易读的赭红线表示，第 21 号公路拥有独立编号标记。
- 商队地图将确定的中文地名直接融合进羊皮纸；无高亮母版与路线状态图保持同一构图，兽爪则独立为透明动画资产。

城镇路线的指示者是岚。画面只露出赤狐前爪、蓝灰工作袖口与货签盒上的铜环；兽爪不是静态换图，而是在地图上滑动、停顿和轻点。村庄路线与流浪者路线沿用相同演出语法，但更换指示角色、爪部造型、袖口以及路线高亮。

这段演出安排在陶穗接受敖浔奕成为临时脚夫之后。此时岚使用“我们”合乎关系进度，也能让地图说明直接引出庆典、城门检查、伪装身份与换装，而不是成为开场硬塞的旁白。

### 3.3 语言为什么能沟通

新时代的“通语”并非与现代汉语完全相同，而是由旧广播、路牌、保存下来的儿童教材和早期聚落口语长期演化而来。

敖浔奕第一次听见商队说话时只能理解约七成：句法熟悉，发音和词义发生偏移。他会通过语境快速补全，而不是由系统直接提供万能翻译。

本章只突出三个陌生词，避免连续讲设定：

- **行脚牌**：商队跨城活动的凭证。
- **保人**：为无本地身份者承担责任的人。
- **短籍**：有期限的临时居民与工作许可。

岚会把敖浔奕异常的说话方式理解为“北边口音”，这成为第一层掩护。

## 四、主要人物

所有姓名均为工作名，正式制作角色立绘前需要用户确认。

### 4.1 敖浔奕／玩家自定义名

- **身份**：ALPHA-01；旧纪元人类改造原型体；现为无身份、无社会常识的龙类兽人。
- **外观**：白色绒毛，蓝色角与毛发装饰，蓝色肉垫，长耳，长尾；体型比普通商队成员略高。
- **本章公开身份**：北边山路失散的行脚人，遭遇塌方后丢失行李和文书。
- **本章目标**：获得安全住处、食物、城市信息和可持续身份。
- **不能公开的内容**：地下设施、ALPHA 编号、休眠年份、篇章-VI、离线核心。
- **表现重点**：他擅长风险判断和结构分析，但不懂本地物价、礼俗、证件和俚语。
- **喜剧尺度**：只允许来自语言错位、尾巴与衣物结构、对物价的误判；不连续抖包袱。

### 4.2 岚（工作名）

- **年龄**：20 岁，成年人。
- **性别**：男。
- **种族**：赤狐兽人。
- **职务**：河谷商队记账学徒、货签管理员、临时跑腿。
- **外观识别**：赤褐毛色、奶油色口鼻与胸毛、深色耳尖；琥珀眼；右耳穿一枚小铜环；尾巴工作时用布带收束，避免扫到货物。
- **初始服装**：蓝灰短工作衣、旧皮肩带、腰侧木制货签盒、手指常沾墨。
- **公开目标**：在本季结束前取得独立记账资格，不再只被当作跑腿。
- **隐性压力**：他本人也只有商队担保的短籍，因此非常清楚“没有保人”意味着什么。
- **性格**：反应快、爱观察、不盲目热情；紧张时话会变多；不喜欢别人把他当孩子。
- **与主角的初始关系**：不是救命恩人或命定同伴，而是最先愿意把规则讲清楚、同时也最先发现主角说辞有漏洞的人。
- **说话方式**：句子偏短，工作时会连报数字；玩笑用于缓和紧张，而不是持续卖萌。
- **关系线种子**：岚替主角补全本地身份，主角则让岚第一次独立完成一份真正影响他人命运的雇签。
- **本章不能做的事**：不能一见面就脸红、投怀送抱、无条件包庇，也不能立刻识破主角来自旧纪元。

### 4.3 陶穗（工作名）

- **年龄**：46 岁。
- **性别**：女。
- **种族**：牦牛兽人。
- **职务**：河谷商队领队。
- **外观识别**：深褐长毛、宽角，左角缠有红色旧布；体型厚重；外套背部有商队白色河纹。
- **目标**：在日落闭门前把货物、人员和账目完整带进城，不承担不必要风险。
- **性格**：不凶，也不热心；凡事先谈责任和交换。她愿意帮主角，是因为主角提供了真实劳动价值。
- **说话方式**：少用修饰，一次只问一个问题；做出承诺后不会反复试探。
- **叙事功能**：提供入城担保，让“被商队接纳”建立在等价交换上。

### 4.4 衡叔（工作名）

- **年龄**：52 岁。
- **性别**：男。
- **种族**：野猪兽人。
- **职务**：车把式与木工。
- **状态**：前一日扭伤踝部，导致商队少一个能搬运和稳车的人。
- **叙事功能**：解释商队为什么需要陌生劳动力；负责判断主角修理方案是否可靠。
- **性格**：嘴硬、手稳，对主角的力气感兴趣，但不会追问隐私。

### 4.5 闻策（工作名）

- **年龄**：34 岁。
- **性别**：男。
- **种族**：黑背犬兽人。
- **职务**：灰桥城验籍门副官。
- **性格**：程序化、敏锐、不刻意刁难人。他的工作就是发现说辞和文件不一致之处。
- **叙事功能**：让入城存在真实门槛；验证玩家此前建立的掩护是否能自洽。
- **原则**：不能写成收钱放行的脸谱反派。主角最终入城，是因为商队有合法担保、劳务事实和可追责地址。

### 4.6 梅婶（工作名）

- **年龄**：约 50 岁。
- **种族**：獾兽人。
- **职务**：南栈院管事兼短籍登记代办。
- **叙事功能**：完成住处和临时身份落地；用日常规则收束章节。
- **性格**：只关心押金、床位、热水和谁负责损坏物品，拒绝宏大叙事。

## 五、城镇路线服装

主角的旧实验服会被折叠、包裹并藏入应急袋底部，不销毁，方便后续作为证物或剧情道具。

城镇路线服装由岚借出商队备用衣物，再由衡叔现场改出尾孔：

- 米白色交领内衫，质地粗糙，领口不完全遮住颈部绒毛。
- 深蓝灰无袖工作长衣，前短后长，方便尾巴活动。
- 暗棕宽腰带，左侧挂临时木质货签，右侧固定应急袋。
- 炭灰宽腿裤，膝部和小腿有布质护片，不做紧身胶衣效果。
- 前臂使用灰蓝绑带，遮住实验服袖口和部分异常接口。
- 短兜帽雨披只在进城和下雨时使用，不遮角；角部有开口和系带。
- 足部按龙类兽人的趾行结构设计软底护足，不强行套人类长靴。
- 尾孔周围有明显但整齐的临时缝线，成为岚与主角第一次轻松对话的来源。

服装视觉关键词：**旧、实用、可活动、能融入商队，但不是乞丐装。**

## 七、逐场剧本

### T01：车辙

**背景**：`bg town_old_highway_edge_day`

**演出**：从序章地表远景淡入旧高速边缘。镜头只显示主角视野中的草、断裂护栏、车辙和远处移动的篷车。

**文本草案**：

> 我没有直接走上路。裸露在开阔地带，意味着把决定权交给第一个发现我的人。
>
> 护栏外的泥土里有三组新车辙。轮距接近，深浅不同，说明车队载重不一；最外侧还混着成排脚印。
>
> 风把说话声送了过来。发音陌生，句子的骨架却熟悉得令人不安。
>
> “……西门……落锁以前……”
>
> 我只能辨清七成。足够判断他们在赶路，也足够让我暂时不要开口。

**选择一：如何观察商队**

1. `保持距离，先数清人数`：`caution += 1`，看见陶穗、衡叔、岚与另外三名背景成员。
2. `靠近断裂护栏，听清他们的谈话`：`lan_affinity += 1`，提前听见岚在核对货签。
3. `观察车辆和路面`（`tech_insight >= 2` 显示）：提前发现后车轮毂存在裂纹，进入 T02 时获得专属台词。

所有选择都进入 T02，不存在“观察错误”。

### T02：断轴

**背景**：`bg town_caravan_broken_axle`

商队后车压过破损接缝，轮毂开裂。车身侧倾，一只货箱向岚的位置滑落。主角不使用篇章-VI，仅凭改造后的反应和力量推住箱体，再用肩部稳定车架。

这样做的理由：

- 主角需要一个主动暴露自己的现实理由。
- 商队需要立刻欠下一份可计算的人情，但不足以无条件信任他。
- 不抢走村庄路线的“猛兽袭击—被人救下”开场。

**关键台词草案**：

岚：“先别松手！右边再垫一块——对，就是你脚边那块！”

> 他的口音比远处听起来更重。我慢了半拍才理解“垫”的意思。

敖浔奕：“我松手以前，你们最好确认它不会向第二个方向倒。”

衡叔：“听得懂话。力气也不小。”

陶穗：“名字。”

敖浔奕：“[player_name]。”

陶穗：“从哪来？”

> 这是第一个不能用真话回答的问题。

**选择二：第一次回应**

1. `先把双手放在所有人看得见的地方`：商队信任 `+1`；表现审慎。
2. `指出轮毂还会继续裂开`：若有技术洞察，衡叔认可；商队信任 `+1`。
3. `只报姓名，不主动补充经历`：不加信任，但增加岚的好奇；岚关系 `+1`。

陶穗不会立即追问到底。她先让衡叔确认车辆，再把主角带到路边谈条件。

### T03：借来的身份

**背景一**：`bg town_caravan_roadside_camp`

陶穗说明现实问题：后车需要临时加固，衡叔无法长时间负重，城门日落后关闭。主角没有行脚牌，也没有看得见的行李。

陶穗：“我不问你为什么从林子里出来，也不替你编来处。”

陶穗：“你帮我们把车送进灰桥。我给你一顿饭、一套不惹眼的衣服、今天的工钱，再把你写进临时雇签。”

陶穗：“进门以后，你去哪里，与商队无关。惹出事，今天以前的事也与商队无关。”

敖浔奕：“边界清楚。可以。”

岚：“先别答这么快。她说的工钱是二十七枚小铜，不包明天。”

陶穗：“现在二十五了。”

岚：“……当我没提醒。”

这段轻松感来自真实讨价还价，不用角色突然变成喜剧演员。

**全屏地图演出**：`map huiyu_kingdom_town_route`

岚把一张磨旧的羊皮纸地图摊在货箱盖上。镜头压近，地图覆盖全屏，环境声保留，BGM 音量轻降。岚的赤狐前爪从画面右下方进入。

第一处停点：兽爪点在首都徽记上，路线尚未高亮。

岚：“这里是灰桥城，荟屿国的首都。”

第二处停点：兽爪沿道路向西南滑动，停在一个手绘商队标记旁；第 21 号公路的赭红线逐段显现。

岚：“我们现在在第 21 号王国公路上。”

第三处停点：兽爪沿高亮道路划回灰桥城，在首都徽记旁轻点两次。

岚：“我们此行正是前往灰桥城进行贸易。眼下正值国王庆典，进城的货队比平日多一倍。”

地图收起时直接回到货箱与众人。陶穗接着说明庆典期间城门盘查更严、日落后不再接收无预约货队，由此进入掩护身份和换装讨论。

> “国王庆典”暂作通俗称呼。正式节庆名称应在王室与宗教设定确定后再命名，现阶段不为了一句台词提前锁死整套政治制度。

**掩护身份**：

岚根据主角的陌生口音，建议把来处写成“北岭旧道”。公开说法为：独自行脚时遇到塌方，与同行者和文书失散，沿旧路向南寻找工作。

玩家可以决定叙述风格：

1. `尽量少说，只保证能工作`：`cover_story = "minimal"`，城门时由陶穗主答。
2. `把塌方、失散和行程整理成完整顺序`：`cover_story = "ordered"`，城门时可亲自回答。
3. `先让岚解释每个证件词的含义`：`cover_story = "learned"`，岚关系 `+1`，解锁城门术语提示。

**背景二／CG**：`cg town_pov_change_clothes`

岚从备用箱里找出衣物。主角在篷车与帆布之间换装，画面只使用手部、腰带、衣料、尾孔和应急袋的第一人称特写。

岚：“你的尾巴……平时都从哪里出去？”

敖浔奕：“从理论上说，衣服应该为身体让路。”

岚：“理论上是。现在它会先把你的腰带掀起来。”

> 他拿走工作衣，在后摆剪开一道缝。剪刀靠近尾根时，我本能地向前挪了半步。

岚：“我还没碰到你。”

敖浔奕：“这是风险预判。”

岚：“北边人都这么称呼怕痒？”

> 我决定暂时不向他解释神经反射和怕痒的区别。

换装结束后获得状态：`town_outfit = True`。

### T04：赶在闭门前

**背景**：`bg town_road_to_greybridge_evening`

这是本章的主要可玩段落。玩家选择一种工作，不改变能否入城，但改变信任、岚关系和后续对白。

#### 工作 A：协助衡叔加固车轴

- 需要观察木撑、绳结和受力方向。
- `tech_insight >= 2` 时，主角可以提出把受力转移到车架纵梁，减少轮毂继续开裂。
- 衡叔不会把现代力学词汇听懂，主角必须换成本地说法：“别让裂口继续吃力，把重量借给中间那根梁。”
- 结果：`caravan_trust += 1`，解锁衡叔以后提供修理铺工作。

#### 工作 B：和岚一起复核货签

- 岚念货物名称，主角按封签颜色和重量重新排列。
- 主角会误解两个时代词义，岚纠正，但不会嘲笑口音。
- 岚发现主角识字方式异常快；`old_world_exposure += 1`。
- 结果：`lan_affinity += 1`，夜间场景增加一段关于“你到底在哪学会认旧字”的对话。

#### 工作 C：走在后车外侧观察路况

- 主角提前发现一处可能让轮子再次陷落的软土，带车队绕行。
- 若 `tested_accelerator` 为真，主角会感到篇章-VI自动进入预备状态，但选择压制启动。
- 结果：`caution += 1`，`caravan_trust += 1`。

**序章状态回响**：

- `gathered_supplies`：可把一段复合绷带交给衡叔固定踝部；商队信任 `+1`，但医疗物资减少。
- `inspected_prototypes`：听见商队按名字点人数时，主角会短暂停顿；只写内心反应，不强行讲述 ALPHA-02—04。
- `tech_insight >= 2`：能认出灰桥城部分城墙是旧高速结构，但暂不说出“高速公路”一词。

### T05：灰桥城门

**背景**：`bg town_greybridge_gate_dusk`

**环境演出**：吊门、排队商队、货箱开封区、盖章台。不要把城门画成纯中世纪城堡；必须看得见旧混凝土桥墩和后期加建的木石结构。

闻策逐项检查：商队行脚牌、货单、人数、临时雇签。主角被单独叫到标线后。

闻策：“名字。”

敖浔奕：“[player_name]。”

闻策：“籍贯。”

> 我知道每个字的意思，却不知道这个时代希望我用什么方式回答。

根据 `cover_story` 出现不同选择：

- `minimal`：看向陶穗，让保人回答。闻策评价“知道什么时候闭嘴不算坏事”。
- `ordered`：亲自复述北岭旧道、塌方和失散，顺序与雇签一致。
- `learned`：使用岚刚教过的“旧道散籍”说法；岚在后方轻轻敲两下货签盒，表示没有说错。

闻策会注意主角没有长期劳动留下的掌茧。主角回答：“过去做的不是搬运工作。”这是真话，但不继续解释。

若 `old_world_exposure >= 1`，闻策会在雇签背面做一个小记号，作为以后城市调查线的伏笔；本章不会因此扣留主角。

最终依据：

- 商队有合法行脚牌。
- 陶穗愿意担任三十日保人。
- 主角当天确实参与劳动，衡叔可以作证。
- 南栈院有可追责住址。

闻策：“短籍只能在南市活动。三十日内没有续签，也没有离城记录，保人和你一起担责。”

敖浔奕：“明白。”

闻策：“你明白得太快了。进去以后让人把规矩再念一遍。”

城门开启，不播放胜利音乐，只把拥挤的环境声逐渐推高。

### T06：南栈院

**背景一**：`bg town_outer_market_evening`

这是主角第一次置身兽人城市。演出重点不是“看见兽人很惊讶”，而是同时出现过量信息：不同种族的步态、气味、叫卖、尾巴空间、适配不同角型的门框和座椅。

> 在远处观察一座城市，与被它包围是两回事。
>
> 门洞比旧时代建筑更高，路边长椅没有统一靠背，摊位之间留着足够尾巴转身的距离。这里的一切都在说明：这个世界不是临时变成了这样。它已经为这样的身体生活了很久。

岚不会进行导游式长篇说明，只提醒三件马上会惹麻烦的事：不要踩别人的尾巴、不要在南市公开拔爪、买东西先问单位。

**背景二**：`bg town_south_caravan_yard_night`

梅婶完成登记：

- 收下陶穗的担保印。
- 给主角一块木质短籍牌，编号写入可重复使用的存档变量。
- 安排一张靠墙通铺床位。
- 扣除两枚小铜作为热水和床具押金。
- 剩余工钱由陶穗当面交付，不欠账。

主角取得：

- `town_permit = True`
- `town_money = 23`（若此前没有额外支出）
- `town_bed = "south_yard_bunk_07"`
- `surface_plan = "town"`

梅婶：“床七。热水在后院，过钟不添。尾巴长的睡外侧，半夜别抽到别人。”

敖浔奕：“这条规则很具体。”

梅婶：“具体，是因为有人赔过三只碗。”

### T07：第一盏灯

**背景**：`bg town_bunk_room_lamplight`

**时间**：入住当晚。其他商队成员已睡或在院内卸货。

岚把改衣服剩下的布条和一张抄写过的城内简图送来。他没有立即离开，因为主角白天对本地常识的陌生程度与“北边行脚人”不完全相符。

岚：“你知道车架怎么受力，能看懂旧桥上的字，却不知道一枚大铜换多少小铜。”

敖浔奕：“听起来确实缺乏一致性。”

岚：“我没准备现在揭穿你。”

敖浔奕：“‘现在’这个限定并不能让人放心。”

岚：“那就当交换。你不问我为什么没有本籍，我也不问你到底从哪座山里掉出来。”

这里出现本章最后一个关系选择：

1. `接受这个边界`：岚关系 `+1`；两人约定明早一起去短籍所。
2. `告诉他一小部分真话：我醒来后失去了能回去的地方`：岚关系 `+2`，但不提时间、设施和人类身份。
3. `反问他为什么愿意担风险`：解锁岚的动机——他曾因没有保人被挡在城外，因此不愿看见同样的事发生；不增加亲密值，但增加人物信息。

岚离开前把灯芯拨低。

> 门关上以后，房间里仍有车轮、脚步和隔墙说话的声音。
>
> 地下设施的安静意味着没有人活着。这里的吵闹则意味着我暂时不必独自证明自己还活着。
>
> 三十日。足够找到下一条路，也足够让一个临时身份产生重量。

显示章节完成界面：

> TOWN ROUTE OPENED  
> 城镇路线·灰桥短籍  
> [player_name] 已取得三十日临时居民身份

本章结束，写入：

- `persistent.town_route_opened = True`
- `persistent.town_met_lan = True`
- `persistent.last_origin_route = "town"`
- `persistent.town_caravan_trust = caravan_trust`
- `persistent.town_lan_affinity = lan_affinity`

## 八、分支变量与规则

建议新增变量：

```renpy
default origin_route = ""
default town_outfit = False
default town_permit = False
default town_cover_story = ""
default town_work_choice = ""
default caravan_trust = 0
default lan_affinity = 0
default old_world_exposure = 0
default town_money = 0
default town_bed = ""
```

变量原则：

- `caravan_trust` 控制陶穗、衡叔和闻策的语气，不控制生死或能否入城。
- `lan_affinity` 代表愿意继续交换私人信息，不直接等同恋爱值。
- `old_world_exposure` 只记录主角表现出的异常知识，不触发第一章抓捕。
- `town_cover_story` 必须在城门对白中保持一致，测试时覆盖三个取值。
- 全局 `resolve/caution/empathy/tech_insight` 只提供少量身份专属对白，不能变成数值门槛堆叠。

## 九、路线入口如何改造

现有 `surface_reveal` 中的“观察道路／带走核心／留下标记”不能继续承担出身路线选择。

建议拆成两层：

1. **离开设施前的可选处理**：带核心、留标记是物品与记忆行为，可执行也可跳过，不决定出身。
2. **真正的地表路线选择**：
   - `走向乡间小道` → 村庄路线。
   - `沿着国道边缘前进` → 城镇路线。
   - `向远处的建筑物探索` → 流浪者路线。

本轮只实现第二项，其余两项先显示“后续章节开发中”或暂时锁定，避免玩家跳入空标签。

## 十三、开发顺序

### 阶段 0：用户定稿

先确认以下四件事：

1. 灰桥城作为荟屿国首都、商队由第 21 号王国公路入城的设定已确定。
2. 商队少年名“岚”、赤狐种族和 20 岁设定是否保留。
3. 城镇线服装方向是否保留。
4. 第一章终点是否确定为“三十日短籍＋南栈院床位”。

### 阶段 1：纯文字可玩原型

- 新建路线目录与变量。
- 改造 `surface_reveal` 后的路线入口。
- 使用现有地表背景和纯色占位背景完成 T01～T07。
- 地图段先用简易线框占位，确认台词、兽爪移动节奏和转场后再绘制正式羊皮纸资产。
- 所有选择、状态回响和持久记录必须可运行。
- 执行 lint，补自动化测试。

### 阶段 2：人物与服装锁定

- 先做敖浔奕城镇服装三视图。
- 再做岚三视图和表情表。
- 人物比例、尾巴根部、角与耳的穿衣结构通过后，才制作陶穗等配角。

### 阶段 3：逐场背景

按 T01 → T02 → T03 顺序制作，每完成一张就接入游戏截图复核，不一次生成八张后统一返工。

### 阶段 4：CG

只在文字、角色和背景构图稳定后制作三张 CG。优先换装 CG，其次断轴 CG，最后城市揭示 CG。

### 阶段 5：声音与节奏

- 环境声先于 BGM。
- 为换装、城门检查和夜谈设置自然停顿。
- 不让每一句对白都触发音效。

### 阶段 6：完整 QA

- 三种掩护说法都能进城。
- 三种工作选择都能进入 T05。
- 有无技术洞察、物资、原型体记录、篇章-VI测试均不报错。
- 自定义姓名正确显示在雇签、短籍和章节完成界面。
- 保存／读取后变量一致。
- 1920×1080、窗口化和全屏下文本不溢出。
- 岚关系与商队信任没有被误当成同一个数值。
- 本章不存在空标签、死循环或无法返回标题的路径。

## 十四、验收标准

城镇线第一章达到以下条件才算完成：

1. 玩家明确知道自己为什么能遇见商队、为什么商队需要他、为什么愿意担保他。
2. 换衣、伪装、工作和进城形成连续因果，不是四段互不关联的事件。
3. 城市制度构成现实障碍，但没有为了制造冲突而让所有工作人员失去常识。
4. 岚拥有独立目标和风险，不围着主角转。
5. 主角保留旧纪元观察能力，同时会因不懂现实规则而需要别人。
6. 第一章结束时，主角只获得临时身份、床位和一个有限可信的人际关系，成长幅度合理。
7. 玩家愿意继续了解岚和灰桥城，但没有被强迫选择恋爱或揭露秘密。
