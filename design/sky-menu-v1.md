# 晴空遗迹主菜单 v1（用户认可，作为 main 默认菜单）

## 约定
- 新主菜单：晴空、两侧遗迹、浅水，大标题居中，小龙落在第三字“旧”上。
- 中央开始／设置／退出，左下读取进度／苏醒记录，右下社交／制作组占位。
- 旧菜单保留为 `main_menu_legacy`，开发时可 `ShowMenu("main_menu_legacy")` 对照；不是面向玩家的主题切换。
- 不改剧情、存档目录、版本号，不自动发布或构建 Android。

## 资产与提示词
全部由内置 image_gen 生成。运行资源放在 `game/gui/sky-menu-v1/`，保留生成原图，不做哈希检查。

- `background.png`：16:9 晴空像素背景；浅青天空，两侧石质遗迹、少量苔藓与旧金属；地平线约六成高，下面浅水；中央留空；不画文字、龙、按钮或发光树。
- `title.png`：真实 Alpha、单行准确五字“风从旧世来”；象牙色石面、深青描边、旧黄铜窄倒角和少量苔藓；第三字“旧”顶部可落脚，不内嵌龙和倒影。
- `dragon.png`：真实 Alpha 的三列两行六姿态图；同一青蓝小龙、金色翼膜，依次振翅、展翼、制动伸爪、落地、收翼、停稳；角色比例一致、完整不裁切。追加透明背景修正，不使用生成失败的棋盘格版本。
- `buttons.png`：真实 Alpha 两列三行带字图；开始／设置、退出／读取进度、苏醒记录／制作组；深青描边、象牙金字面，无重型按钮框。
- `cloud.png`：真实 Alpha、横向稀疏的奶白像素云层；运行时缓慢漂移，降低动效时静止。

运行时使用 Crop 保留独立图层，不修改源图片。龙以爪部接触基线定位；水纹只作用水面与倒影。首次入场可点击跳过，返回二级菜单不重播。动效开关关闭水纹与后续入场。

## 验证与复现
2026-09-12 最终验证：以下五个测试全部 PASS；Ren'Py lint、compile 与 git diff --check 均通过。

- `sky_menu_intro`：入场关键帧、动效开关、设置返回。
- `sky_menu_skip`：跳过入场不会同时开始游戏。
- `sky_menu_save_restore`：隔离存档中保存真实法庭选择，返回标题后读取并核对剧情状态。
- `sky_menu_navigation`：菜单入口、退出取消、开始及暂停。
- `sky_menu_keyboard`：方向焦点、确认打开档案与设置、返回。使用队列按键事件，避免测试框架 Keysym 节点先移动鼠标而干扰焦点。
- 运行 `python design/run_sky_menu_tests.py`，每个测试独立启动；结果写入被 Git 忽略的 `tests/` 日志，测试完成后只结束自己启动的进程。
- 入场截图及最终静态画面已检查龙落脚、透明边缘和标题裁切。用户仍负责动效气质和视觉取舍的最终验收。
- 此轮仅 Windows 验证，未打包 Android。用户授权将本版发布到 main；改菜单前完整状态保留在 codex/legacy-menu。旧存档目录保持不变，本轮菜单改动不修改剧情。
