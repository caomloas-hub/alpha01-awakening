# 村庄路线 Pt.1 开发计划

状态：规划稿，尚未实现、尚未生图。本文替代开始新路线前的口头方案；不是宣称应用已切换到 Plan 模式。

## 本轮边界

作者已定：乡间小道 → 猛兽袭击 → 村中少女救援 → 昏迷 → 换衣 → 在村庄落脚；少女是本路线专属人物，后续有身份对话和个人支线。出身由走哪条路形成，不做哲学或道德测验。本阶段不汇合三条路线，不拓展城镇 Pt.2。

提案：第一部分结束于主角在村里度过第一夜，取得临时留宿的允许，约定次日一项力所能及的帮工。正式被接纳为村民留给后续事件，避免受一次救援就立刻获得全村信任。

村名、少女姓名/种族、猛兽外形和服装外观尚未敲定。正文草稿可使用工作称呼，不把它们静默写成世界观定案。

## 人物与关系设计

| 人物 | Pt.1 中的作用 | 此刻关注什么 | 不应提前知道 |
| --- | --- | --- | --- |
| 主角 | 从自救到接受具体帮助；仍保留判断与选择 | 伤势、袋子是否还在、门口和救命人的意图 | 村中人情、少女身世、此地行政规则 |
| 救援少女 | 熟悉林路，带主角脱险，后来成为专属关系线 | 把伤者带回去、解释为何带回陌生人 | 旧世界实验、两千年休眠、未展示的义体能力 |
| 照料伤者的村人 | 处理伤势、衣物，说明身体与行动限制 | 伤口、清洁衣物、能否独自行走 | 主角隐藏的道具功能与真实身份 |
| 安排留宿的村人 | 给出落脚条件，不充当终局审判者 | 夜间安排、工具与粮食、来人是否惹事 | 主角一定可靠或一定有罪 |

后两种职能可由同一人物承担，先用三名主要 NPC 完成可玩切片。种族与体型维持日系萌系福瑞，不以肌肉兽人承担当力气角色。救援少女要有自己的正在进行的事，不只作为主角的救命工具；具体职业待定，不强行配置口癖、秘密创伤或爱情承诺。

## 场景顺序与可玩内容

| 段落 | 事件与转折 | 玩家能做的事 | 所需画面 |
| --- | --- | --- | --- |
| V01 林路 | 沿现有足迹走入林带；先听见近处异常，再看见威胁 | 观察退路、放慢步子，保持同一遭遇结果 | 已有林间小径概念图可作入口；近景须看适配 |
| V02 遭遇与救援 | 猛兽切断去路；主角尝试脱身，少女利用熟悉的地形把他引离攻击范围 | 选择自救办法；不把谨慎选项写成原地等死 | 第一人称救援 CG、必要的林间近景 |
| V03 意识断续 | 脱险后体力与伤势让主角撑不住；只呈现能听见、感觉到的片段 | 不在昏迷中进行完整战略对话 | 黑场/短转场、已有音效按需复用 |
| V04 醒来 | 陌生屋内醒来，先确认身体、门和应急袋，再询问救援 | 先问救命人 / 先问伤势与东西去向 | 照料房背景、穿好村庄衣物后的 CG |
| V05 交代与认识地方 | 少女说明发现经过；照料者说明伤势与衣服处理 | 决定说多少眼前实情，不编新出身长篇自白 | 屋内立绘；村用地图作为可选资产 |
| V06 留宿条件 | 主角在可行动范围内观察村子；村人安排床位，问明日能做什么 | 选一项与伤势相容的轻活，不即时奖励万能技能 | 村中公共院落、必要角色立绘 |
| V07 第一夜 | 与少女一次短谈；归还/收好具体物件，约定明早的事 | 关系表达的细小差异，不直接绑定恋爱路线 | 村庄住处夜景，可与照料房共址昼夜变化 |

各段先写完整草稿，再确认需要哪一张资产；不要为了凑 CG 数量把一次对话分到多个地点。第一次切片只做 V01—V04，用户认可后再做 V05—V07。

## 遭遇合理性：写作前先锁定

- 危险来自非智慧野生动物；不把有完整语言的福瑞村民含混称作野兽。具体外形需作者定调。
- 主角刚苏醒、不熟悉新身体及林地；仍会尝试避开攻击。不能为了让少女登场，突然忘记序章展示过的能力。
- `tested_accelerator` 决定他如何判断加速的代价，不等于拥有/没有义体。若真正启动会改变能力规则或后续暴露，应单独讨论，首稿优先不新增启动事件。
- 救援依靠可见的地形、时机与当地经验，不用少女突然一击秒杀解释全部。第一稿可提“引到窄道/隔开攻击范围”，具体动作与武器在构图前定。
- 少女不独自徒手拖走一个失去意识的成年人长距离跋涉：首稿安排脱险后附近村人接应；交代接应如何到场，避免随叫随到。
- 昏迷原因和伤势前后一致，不一醒就劈柴搬重物。受伤不能只为换衣而存在。
- 换衣只作照料事实说明：旧衣破损/沾污及包扎需要，醒后给主角解释。保管旧实验服与应急袋，不默认照料者识破装置。无需展示昏迷脱衣或裸露画面。

以上是待写入首稿的方案，不是已发生事实。若需要新增角色、生存能力或道具，先在首稿列明。

## 序章状态承接

- 保留 `player_name`、法庭选择、审慎/共情/技术洞察、原型体调查、物资取得与加速测试。
- `gathered_supplies=False` 仍有空应急袋；不能使用未取得的复合绷带。True 可有一处照料回调，但不把过期药品写成可靠治疗。
- 没检查原型体，不引用主角逐个念编号的经历。玩家见过时代年表不等于少女知道人类历史。
- 村庄没有城镇工作衣、岚关系、商队担保或南市短籍。不能从 persistent 的其他周目读取这些来补当前叙述。
- 离线核心目前是序章可选带走的物品；如本路线需要实质使用，新增独立持有状态及旧存档兼容方案，再实现。不要以 `surface_plan` 被别的用途覆盖后的值或上次通关记录判断持有。

## 技术落点

保留 `origin_route_choice` 两个初始选项及 120 秒隐藏流浪者逻辑。村庄入口仍接在现有 `village_route_preview` 契约上；实现时可保留该标签作为转发兼容入口，新增 `village_route_start`、分段标签与 `village_route_complete`。

建议文件：`game/routes/village/village_route.rpy`、人物定义、资产定义分别独立。暂存人物工作名不进入最终存档标识。

提议新增的最小状态：村庄衣物、留宿许可、伤势阶段、救援少女关系、约定的轻活。命名、默认值、范围与写入时机在实现前列清；不复用城镇变量。不是每个对话选项都需要新数值，优先文字回调。

持久字段仅用于解锁/通关摘要。本周目关系与持有状态使用普通存档变量。替换旧预告结尾时同时更新依赖 `village_preview` 的测试断言，不能把旧测试失败当成删测试理由。

## 美术与声音

先人物设定，再救援构图，再醒来穿衣与屋内环境。必要的村用地图由当地绘图者视角出发，突出水源、林路、田地与邻村；不复用商队贸易地图。地图文字可以与纸面一并生成；指示兽爪独立，仅在需要指点时制作。

1920×1080，第一人称；每张明确是否露爪、衣袖，不默认露主角全身。换衣后尾孔、前后袖口、绷带与伤势需互相对应。地图、昼夜屋景可延后，不作为 V01—V04 最小切片的前置负担。

声音先小范围：林地底噪 → 一次近处枝折/逼近 → 救援瞬间 → 意识淡去 → 屋内细响。动物声要和最终生物设定吻合；不用城市人群声铺村庄，不用持续咆哮逼玩家读字。素材授权记录沿用当前音频文档流程。

## 开发与验收顺序

1. 作者定调少女、村名、野兽及救援动作；必要时先给少量候选，不批量生成。
2. 写 V01—V04 首稿，用新 Skill 复查知情、行动顺序、伤势和可选经历。
3. 每次生成并接入一张必要资产，跑通对应场景，交作者验收。
4. 完成 V05—V07，补轻量选择回调与第一部分结尾。
5. Windows lint、compile、两类序章承接（少调查/多调查），以及受影响的城镇与隐藏入口回归；核对变量和终点。
6. 明确区分状态夹具与真实计时、打开存档页与实际读档恢复。只报告执行过的测试。完成后再决定是否打包 Android，不自行安装或发布。

不以哈希、逐像素截图、字数指标或 AI 检测评分验收。工程跑通由 Codex 负责，剧情和画面定调由作者负责。
