# 声音设计计划

## 当前实施状态

第一轮先完成“旧王国公路—验籍门”试听小样，不全量铺设第一章：

- 林缘至城门使用独立循环风声，进入南市前淡出；
- 与商队成交、展开地图时引入一首候选行路曲，穿过门洞后淡出；
- 断轴、地图展开、兽爪点图已从通用 `ui_ping.wav` 中拆分；
- 南市、南栈院、通铺房以及完整 UI 声组暂不接入，待用户试听小样后再决定声音方向。

已使用素材及许可见 [THIRD_PARTY_AUDIO.md](THIRD_PARTY_AUDIO.md)。

## 当前问题

项目目前只有 `facility_hum.wav` 与 `ui_ping.wav`。同一个提示音同时承担章节提示、地图节点与界面悬停，缺少空间层次，也无法表现地下设施、王国公路、城门、南市和通铺房之间的材质与距离差异。

## 第一轮重构

声音分为四层，分别控制，不把所有反馈塞进默认 `sound` 通道：

1. **环境底层**：可无缝循环的空间声，例如设施通风、黄昏风声、车轮与牲口、城门人群、南市远景、栈院夜声。
2. **事件动作**：只在动作发生时播放，例如断轴崩裂、木轮受力、盖章、木牌落入掌心、门轴、布料和脚步。
3. **界面反馈**：悬停、确认、返回、不可用分别使用短而轻的声音；章节标题和关键获得提示不再复用普通悬停音。
4. **音乐与主题动机**：最后加入。先用环境声建立世界可信度，避免用音乐掩盖场景缺声。

| 场景 | 环境层 | 关键动作 |
|---|---|---|

## 素材准入规则

- 首选 **CC0**；其次为允许商业使用的 **CC BY**，并在 `THIRD_PARTY_AUDIO.md` 逐项署名。
- 不采用 CC BY-NC 作为正式资产。项目目前即使非商业，未来一旦收费、众筹或上架就会形成迁移成本。
- 不因网站写着“free”就默认可用；每个文件保留作者、原始页面、文件名、许可证、下载日期和修改记录。
- 不把第三方原始素材包整体提交到仓库，只提交游戏实际使用、经过裁切或混音后的文件；许可证不允许再分发原文件时，成品中也必须以不可单独提取的合理方式使用。
- 循环环境声先检查接缝、底噪突变和响度；动作声至少准备轻/中/重或两到三种随机变体，避免连续点击出现“机关枪感”。

## 推荐来源

- Kenney：资产页明确标注 CC0，适合 UI、机械与基础反馈音。
- Freesound：只按单个声音页面的许可证选取；优先筛选 CC0，使用 CC BY 时必须登记署名。
- OpenGameArt：可用于补充游戏向音效，但要逐项读取许可证和署名要求，不能把站点本身当作统一授权。
- Sonniss GameAudioGDC：适合高质量环境与拟音，但使用的是专门 EULA，不等同于开源或 CC0；下载当日应保存对应许可证版本。

## 接入顺序

先替换 UI 悬停与确认音，再完成城镇线六个场景的环境循环和关键动作声。每接入一个场景，只验证加载、循环、音量和转场，不用波形或截图比较代替实际听感验收。
